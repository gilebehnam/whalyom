# Commands

106 ready-made slash commands. In Claude Code type `/` and the name; as a plugin they are `/whalyom:<name>`. Generated by `node tools/commands.mjs`; edit the catalog there, not these files.

## Start

| Command | What it does |
|---|---|
| `/whalyom-new <slug> [domain]` | Add a product: a workspace from a domain or a short brief |
| `/whalyom-onboard <product-slug>` | Onboard a product: crawl, ICP, competitors, claims, profile and a 30-day plan |
| `/site-audit <domain or slug>` | Instant marketing audit of a site: SEO, AI search, speed, conversion and trust |
