## Section B — Master brief mapped to the implementation

The brief describes a TypeScript/React monorepo (`src/…`). Whalyom instead runs **natively on Claude Code**: agents are Claude Code subagents, orchestration is skills and workflows, deterministic logic is Node scripts in `tools/`, and the UI is a claude.ai artifact. ## Section C — What still needs the owner or is not built

- **Accounts and keys:** ad accounts with payment methods, Meta System User token, Resend, Stripe read key, site repository, webhooks or n8n for other channels; GitHub repository secrets for the hourly daemon. Whalyom cannot create accounts, add payment methods or accept platform terms.
- **Keys for the native connectors:** X (posting and ads), Reddit Ads, Apple Search Ads, Google, Microsoft, TikTok and LinkedIn all have native connectors in tools/connectors/; each needs the owner's API keys. Reddit and Apple request shapes are marked "verify against current API docs" until run on a live account.
- **Self-serve sign-up and billing for other companies:** built (tenants, plans, Stripe Checkout, signed webhook, edge routes; see Section B) but not yet run against live Stripe. The owner still has to create the Stripe products and recurring prices (growth, scale, agency), add the webhook endpoint `https://<edge>/billing/webhook` for `checkout.session.completed`, `customer.subscription.updated`, `customer.subscription.deleted` and `invoice.payment_failed`, and set `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` and `STRIPE_PRICE_GROWTH` / `STRIPE_PRICE_SCALE` / `STRIPE_PRICE_AGENCY` in the server's `.env` (see `deploy/CLOUD.md`). There is no sign-up web page yet (the API is ready for one), and tenant workspaces share the hub's single agent cycle and repository.
- **Keys for the 2026-11-04 connectors:** Instagram and Facebook (Graph API tokens with app review), TikTok posting (Content Posting API token, audited app for public posts), Twilio voice (account, number and a public https webhook base), Amazon Ads and Walmart Connect (advertiser accounts), and one image or video provider (OpenAI, Stability, Runway or Luma) plus a `creative.monthly_cap` the owner sets. Calling consent and do-not-call lists are the owner's responsibility per market.
- **Real-time push from the cloud:** `tools/cloud/realtime.mjs` streams the live documents from the edge (`GET /live/stream`, SSE) for hosted clients. The Command Center artifact also updates instantly while a Claude session runs; the hourly GitHub daemon writes the same state files to the repo, and the next session pushes them.
- **Lead scraping and mass DMs:** not built on purpose. Whalyom uses public business sources, consented lists and platform-compliant outreach only; it does not evade spam filters or platform rules.
- **Results:** no system can guarantee revenue multiples. Whalyom measures, learns and reallocates; outcomes depend on the product and market.
