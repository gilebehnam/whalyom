## Frameworks and methods

- **OWASP Top 10 for LLM Applications 2025: LLM01 Prompt Injection, LLM02 Sensitive Information Disclosure, LLM03 Supply Chain, LLM04 Data and Model Poisoning, LLM05 Improper Output Handling, LLM06 Excessive Agency, LLM07 System Prompt Leakage, LLM08 Vector and Embedding Weaknesses, LLM09 Misinformation, LLM10 Unbounded Consumption. - **The Universal Commerce Protocol (ucp.dev) is an open standard for agents, platforms and businesses, with specification, SDKs and reference implementations on GitHub under the Apache 2.0 license. Co-developers listed include Google, Shopify, Amazon, Walmart, Stripe, Booking.com and Marriott; Visa, Mastercard and PayPal are listed as endorsers. Capabilities are catalog search and lookup, cart building, identity linking (OAuth 2.0), checkout and order management; it runs over REST and JSON-RPC with support for AP2, A2A and MCP. Businesses remain merchant of record. A lodging spec is in draft and food ordering is coming soon.** (2026-11-03; official, medium) [source](https://ucp.dev/) `K-a1354620ad`
- **The C2PA Technical Specification (Content Credentials) is at version 2.5, listed as October 2026. A C2PA Manifest combines assertions, a claim and a claim signature. Soft bindings (such as fingerprints or invisible watermarks) let a manifest be recovered if metadata is stripped. Keep Content Credentials on AI-generated ad and social assets through export.** (2026-10-01; official, high) [source](https://spec.c2pa.org/specifications/specifications/2.5/specs/C2PA_Specification.html) `K-b002df88ac`
- **The current Model Context Protocol specification is version 2026-07-28 (JSON-RPC 2.0; hosts, clients, servers). Servers offer resources, prompts and tools; clients can offer elicitation; tasks, MCP Apps (inline UI) and Skills over MCP are opt-in extensions. Security principles: users must consent to all data access and operations, hosts must get explicit consent before invoking any tool, tools are treated as arbitrary code execution, and tool annotations are untrusted unless from a trusted server. MCP cannot enforce these; the host must.** (2026-07-28; official, high) [source](https://modelcontextprotocol.io/specification/latest) `K-3d126d9271`
- **NIST AI Risk Management Framework 1.0 was released 26 Jan 2023 with four core functions (Govern, Map, Measure, Manage); the Generative AI Profile, NIST AI 600-1, was released 26 Jul 2024 with risks and actions specific to generative AI. NIST says AI RMF 1.0 is being revised under the White House AI Action Plan, and on 7 Apr 2026 it released a concept note for a critical-infrastructure profile. Map agent evaluations and red-team results to these functions in the self-evolution loop.** (2026-04-07; official, high) [source](https://www.nist.gov/itl/ai-risk-management-framework) `K-11c0ebcaec`
- **Visa's Trusted Agent Protocol (14 Oct 2025, built with Cloudflare) lets merchants tell approved AI shopping agents from bad bots: agents sign requests with agent-specific cryptographic signatures based on HTTP Message Signatures and aligned with Web Bot Auth, carrying Agent Intent, Consumer Recognition and optional Payment Information. It supports agent-driven guest and logged-in checkout with minimal site changes. Available via Visa Developer Center and GitHub; initial specs cover the Visa network only. Do not let bot defenses block signed agents.** (2025-10-14; primary, high) [source](https://usa.visa.com/about-visa/newsroom/press-releases.releaseId.21716.html) `K-573830affc`
- **Google's Agent Payments Protocol (AP2, announced 16 Sep 2025) uses cryptographically signed 'Mandates' as proof of what the user approved: an Intent Mandate records the user's instructions and, for delegated tasks, rules such as price limits and timing; a Cart Mandate locks in the exact items and price when the user approves a cart. Together they form a non-repudiable audit trail from intent to cart to payment. AP2 extends A2A and MCP, supports cards, bank transfers and stablecoins (A2A x402 extension with Coinbase, the Ethereum Foundation and MetaMask), and was developed with 60+ payments and technology companies.** (2025-09-16; primary, high) [source](https://cloud.google.com/blog/products/ai-machine-learning/announcing-agents-to-payments-ap2-protocol) `K-93013a7682`

## Rules

- **OWASP LLM01:2025 Prompt Injection: direct injection comes from user input; indirect injection comes from external content (websites, files) that the model processes. OWASP says no foolproof prevention is known, only layered mitigation: constrain the model's role, validate output formats with deterministic code, filter inputs and outputs, enforce least privilege, require human approval for high-risk actions, segregate and mark untrusted external content, and run regular adversarial testing.** (2026-11-03; official, high) [source](https://genai.owasp.org/llmrisk/llm01-prompt-injection/) `K-0a3bd69f71`
- **YouTube requires creators to set 'AI use' at upload for realistic AI-generated or meaningfully altered content: a real person saying or doing what they didn't, altered footage of real events or places, realistic scenes that never happened, or AI music as the main focus. Not needed for clearly unrealistic or animated content, minor edits, or AI used only for scripts, titles, thumbnails or ideas. YouTube may auto-label via its own tools or C2PA metadata. Disclosure alone does not limit reach or monetization; repeated non-disclosure can mean removal or YPP suspension.** (2026-11-03; official, high) [source](https://support.google.com/youtube/answer/14328491?hl=en) `K-43608d5348`
- **Anthropic's Usage Policy effective 12 Nov 2026: consumer-facing chatbots and agents must disclose that users are interacting with AI rather than a human, at the start of each session or in the interface; political content must not be false or misleading, and mass automated messages to voters must not conceal their artificial origin; high-risk AI recommendations (legal, medical, finance, credit, employment, housing) need meaningful review by a qualified person.** (2026-11-03; official, high) [source](https://www.anthropic.com/legal/aup) `K-558ee2c6d4`
