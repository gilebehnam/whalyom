Ads inside them are limited to English in a set of markets including the US.** (2026-10-28; official, high) [source](https://support.google.com/google-ads/answer/16297775?hl=en) `K-463240a859`

The same update lets new advertisers build a first Performance Max campaign from sign-up using AI, with budget, bids, copy and assets editable before launch.** (2026-10-28; official, high) [source](https://about.ads.microsoft.com/en/blog/post/october-2026/build-steer-and-measure-your-campaigns-with-ai-whats-new-in-microsoft-advertising-this-october) `K-8530245ef4`
