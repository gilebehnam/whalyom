# Code of conduct

Whalyom follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, critique ideas and not people, and help newcomers. Harassment, discrimination and personal attacks are not welcome in issues, pull requests or any project space.

Report unacceptable behaviour privately to bjafaribox@gmail.com. Reports are read by the maintainer and kept confidential.
