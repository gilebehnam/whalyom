# Changelog

Every release keeps `npm test` green. Numbers are counted by `npm run stats`.

## 1.0.0 (first public release)

- **Workforce:** 536 AI agents in 28 departments and 6 layers: 30 department heads, 59 micro agents for single fast jobs, the rest specialists.
- **Six departments added before release:** Product Marketing; Video & Audio Studio; Customer Success & Support; Web & MarTech Engineering; Local & Field Marketing; Community & Events, each with its own method skill and skill pack.
- **Commands:** 106 slash commands, from `/site-audit` and `/growth-plan` to one command per specialist job.
- **Rules:** 50 house rules, each naming the code that enforces it.
- **Knowledge:** 1,152 verified facts from 46 official and research sources in 28 topics.
- **Engine:** 73 Node scripts: the daemon, funnel, CRM, sequences, inbox, lead scoring, bandit tests, attribution with an MMM-lite, AI-answer visibility, competitor watch, brand voice guard, the local Command Center and the `whalyom-core` MCP server.
- **Harnesses:** Claude Code (plugin or workspace) and Codex (skills, commands as prompts, `AGENTS.md`), on macOS, Linux and Windows.
- **Docs:** README in ten languages.
