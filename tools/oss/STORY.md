# The story

Most good products die quietly.
Not because they are bad, but because nobody hears about them.

The people who build them know this.
They also know what the fix costs: a marketer, a copywriter, an SEO person, someone for ads, someone to answer leads at eleven at night.
A small team cannot pay for that. So the product waits.

Whalyom started from one question:
**what if that whole department lived inside the terminal you already code in?**

## One department, then twenty-two

It began as one agent that wrote a growth plan.
The plan needed research, so a crawler and a competitor analyst joined.
Research without copy was useless, so writers came, then editors to check every fact.
Copy without a page was useless, so a landing builder came. A page without traffic, so SEO, ads and communities.
Traffic without answers lost the leads, so a sales team came, and a funnel to track every one of them.

Each time a step failed, the fix became an agent, a rule or a script.
That is how it grew to {{agents_fmt}} agents in {{departments}} departments, {{skills_fmt}} skills and {{commands}} commands.
Nobody planned the number. The work did.

## What could go wrong

An agent with an email connector is an agent that can email the wrong people.
An agent with an ad account can spend a month's budget in an afternoon.

So the most important part of Whalyom is not an agent at all. It is {{rules}} rules, and code that enforces them:
one executor that sends anything, caps no prompt can raise, a kill switch for ads that waste money,
consent checked again right before every message, and the owner's yes before anything leaves.
A model can be talked into anything. A spend cap in code cannot.

## The part that keeps learning

Marketing knowledge goes stale fast. A rule that was true about ads in spring is wrong by autumn.
So Whalyom reads {{knowledge_sources}} official and research sources, and a verifier agent tries to prove each new fact wrong before it is kept.
{{knowledge_notes_fmt}} notes survived so far.
Every agent reads its department's brief before it acts, and every result goes back into what the system learned.

## Why it is free

The engine that does the work belongs in the open.
You run it on your own Claude Code, with your own subscription, on your own machine. Your leads never leave it.

For people who want the result without running anything, there is a hosted version.
Same agents, same rules, on our servers, around the clock.

If Whalyom helps your work get found, a star helps it get found too.
